# YuvaIntern Data Science with Python Internship Project

## Project
Iris Species Analysis and Classification

## Technologies
Python, Pandas, NumPy, SciPy, Matplotlib, Scikit-learn

## Week-wise Work
- Week 1: Data Acquisition, Cleaning and EDA
- Week 2: Advanced Data Visualization and Storytelling
- Week 3: Statistical Analysis and Hypothesis Testing
- Week 4: Machine Learning Model Development and Evaluation
- Week 5: Comprehensive Project Reporting and Strategic Recommendations

## Dataset
Public Iris dataset provided through Scikit-learn.

## Key Results
- 150 observations
- 3 species: setosa, versicolor, virginica
- Missing values: 0
- Duplicate rows: 0
- Logistic Regression accuracy: 93.33%
- Weighted precision: 93.33%
- Weighted recall: 93.33%
- Weighted F1-score: 93.33%

## Statistical Finding
Welch's t-test found a statistically significant difference in petal length between versicolor and virginica (p < 0.05). One-way ANOVA also found significant differences across the three species.
